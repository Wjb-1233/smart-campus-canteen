# 项目答辩提纲（可直接改成 PPT）

## 1. 背景痛点
排队久、选餐难、支付慢、营养缺失、浪费严重、管理滞后。

## 2. 方案总览
SpringBoot + Vue3 + MySQL + Redis，纯软件实现，AI Coding 贯穿需求-编码-测试-文档。

## 3. 技术亮点
1. Redis Lua 原子库存
2. 标签体系 + 混合推荐
3. 订单三级状态机 + WebSocket
4. 营养预警与运营大屏

## 4. AI 效能（示例口径，答辩时替换真实数据）
- Prompt 驱动 API/页面/测试生成
- 人工审查聚焦业务边界与安全
- 建议统计：AI 生成代码占比、单功能耗时对比

## 5. 演示路径
登录 → 推荐 → 标签搜索 → 下单 → 档口接单 → 营养周报 → 数据看板
