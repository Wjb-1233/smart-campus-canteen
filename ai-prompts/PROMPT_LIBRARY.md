# AI Coding 提示词模板库

## 1. 后端开发者

### 用户脱敏聚合接口
```
请基于 Spring Boot 3 + MyBatis-Plus 生成用户详情接口：
- 手机号脱敏（138****8001）
- 返回院系、近7日消费总额、营养达标率
- 统一 Result 包装，含全局异常处理
```

### 标签组合检索
```
生成菜品搜索接口，支持按“低脂”+“清真”+“主食”三标签组合检索，
返回热度排名与余量提示，SQL 使用 GROUP BY HAVING 保证标签全匹配。
```

### 下单库存替换
```
生成下单接口：Redis Lua 原子扣库存；库存不足时按相同标签寻找替代菜品；
返回 replaceLogs；同步更新 MySQL stock 与营养日统计。
```

### 管理员只读拦截器
```
为食堂管理员生成权限校验拦截器，仅允许访问 /order/statistics、/dish/report 等 GET 路径，
拒绝所有 POST/PUT/DELETE，返回标准错误体 {code,message,data}。
```

```
使用 Vue3 Composition API + Element Plus 生成菜品搜索页：
勾选式标签筛选、关键词模糊匹配、结果按热度排序、点击跳转详情。
```

### 营养雷达图
```
使用 ECharts 在菜品详情页绘制热量/蛋白质/脂肪/碳水雷达图，主题色使用校园蓝 #1a5f9e。
```
